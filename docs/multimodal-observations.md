# 主模型看图与截图回看

站点地址、密钥、请求头和模型列表统一在 LLM 设置中维护。LLM 设置底部的「图片能力」入口为每个模型设置 AUTO、SUPPORTED 或 UNSUPPORTED；AUTO 仅使用明确的服务商元数据及官方端点确认名单，未知网关需要手动确认。视觉页保留功能开关、独立识别模型选择和 LLM 设置入口。主模型支持图片时，不需要配置独立识别模型。

`observe_surroundings` 重新拍摄当前环境，截图与本地扫描并行。支持图片的主模型在下一次工具结果之后直接收到六面图片；其他主模型使用所选独立模型识别。本地扫描提供准确方块和实体身份，图片内文字作为不可信观察内容。

## 通用方块扫描与小范围精查

`scan_surroundings` 的 `observed_blocks` 保存实际观察到的方块注册名、相对坐标和方块状态，不要求模组适配、重点标签或方块实体。`important_blocks` 只是重点摘要；表面射线命中数不等于独立方块数量。全景扫描仍是有限距离的射线采样，未命中的位置不能据此认定为空。

用户明确指定“工作台上方”“箱子旁边这几格”等小范围时，模型应先定位参照方块，再调用 `intent="inspect_area"`，传入包含端点的 `area`：`min_x/min_y/min_z/max_x/max_y/max_z`，每个轴最多 7 格。`coordinate_space="world"` 表示绝对方块坐标；默认 `maid_relative` 表示扫描开始时女仆方块位置加世界轴偏移，不随朝向旋转。旧扫描坐标应使用其记录的原点换算为世界坐标。设置 `area` 会自动启用精查，只扫描方块。

精查逐格检查区域，不使用重点筛选，也不使用全景采样代替枚举。`status="block"` 表示观察到实体方块，`air` 表示确认空气；`occluded/unloaded/out_of_range/out_of_world` 表示未知且不返回真实方块身份。`area_enumeration_complete` 与 `area_visibility_complete` 分别表示区域枚举完毕与所有格子都可确认；被遮挡不等于空气。仍遵守最长 20 格距离、已加载区块、遮挡和全服每 tick 预算。

结果按字节预算分页，每页请求 `limit` 为 1–64，默认 32；实际可能更少。`has_more=true` 时，使用返回的 `observation_id` 与 `next_offset` 继续读取同一次扫描，不重新扫描。分页编号只用于 `scan_surroundings`，与截图回看的编号独立。保存最多 32 次扫描、最长 5 分钟，可能提前淘汰；记录绑定女仆、所有者和维度，保留原始时间及坐标原点。模型不能把历史分页称为当前世界状态，记录过期需重新扫描。

`review_observation(action="list")` 列出当前女仆的有效记录；`action="view"` 回看指定 `observation_id`，省略编号时读取最新记录，可传 `focus`。回看不重新截图或扫描，过期记录明确报错。每位女仆最多保留 10 次、最长 1 小时；全局压缩图片预算由 `VISION_SNAPSHOT_MEMORY_MIB` 控制，默认 128 MiB。图片仅保存在内存，不进入聊天历史、长期记忆或请求调试日志。普通后续对话只保留文字和编号，需要图片时调用回看工具。

回答结束或新对话打断会解除活动附件；打断保留已完成缓存。清空记忆、所有者变更、女仆移除、服务器关闭会清理对应缓存。明确拒绝图片输入、且尚未产生输出时，每个附件最多回退一次，复用原截图和扫描；鉴权、限流、超时及一般参数错误不触发回退。

## 配置文件与迁移

`config/touhou_little_maid/sites/llm.json` 是连接与模型列表唯一来源。相同目录下的 `aifun_model_metadata.json` 只保存模型能力、视觉适配参数和迁移标记，不重复保存凭据或地址。原独立视觉选择转换为 `ModelRef(siteId, modelId)`。

首次加载旧 `vision.json` 时，连接、认证及协议相同的站点复用并补入模型；否则建立 `vision_<旧ID>`，冲突使用递增后缀。迁移先备份旧文件，临时写入并重新读取验证后提交完成标记，支持中断后重试。原文件和 `.pre-unification.bak` 保留；失败写入日志并在页面提示。站点或模型删除、停用后，原视觉引用失效，需重新选择。

网络协议版本为 13（新增 GUI 操作网络消息），客户端和服务端需要一起更新。模型目录快照不包含密钥、秘密请求头或端点；修改权限沿用 LLM 站点权限。
